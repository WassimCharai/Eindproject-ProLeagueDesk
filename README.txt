PROLEAGUE DESK – BRONCODE
============================

Bedankt voor uw interesse in mijn eindproject.

ProLeague Desk is een desktopapplicatie ontwikkeld als eindproject van mijn
opleiding Softwareprogrammeur. De applicatie is ontwikkeld met:

- C#
- WPF (Windows Presentation Foundation)
- .NET 10
- SQLite
- Entity Framework Core
- BCrypt voor wachtwoord hashing

DOEL VAN DE APPLICATIE
----------------------
ProLeague Desk is een beheersysteem voor een voetbalcompetitie. Afhankelijk
van de gebruikersrol kunnen gebruikers onder andere teams, coaches,
scheidsrechters en wedstrijden beheren of opvolgen.

De applicatie bevat drie gebruikersrollen:
- Admin
- Coach
- Scheidsrechter

STARTEN
-------
1. Clone of download deze repository.
2. Open `ProLeagueDesk.slnx` in Visual Studio.
3. Herstel de benodigde NuGet-packages.
4. Build en start het project.
